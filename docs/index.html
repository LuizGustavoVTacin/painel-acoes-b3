Capítulo 01 · Visão geral

Acompanhe suas ações da B3 sem pagar nada

Um dashboard pessoal que roda só no seu computador: mostra o preço das ações que você escolher e quanto cada compra está rendendo, usando apenas fontes de dados gratuitas e sem cadastro.

▦

Grade de ações

Quadrados iguais com logo, código e preço atual. Até 50 ações.

⟳

Cotações automáticas

Yahoo Finance como fonte principal e brapi como reserva, a cada 5 min no pregão.

↗

Ganho ou perda

Preço médio das suas compras e seta verde ou vermelha com o percentual.

⚑

Nunca quebra

Se uma API falhar ou pedir pagamento, o app avisa e mantém o último preço.

Onde o projeto está

O desenvolvimento segue etapas curtas. Cada uma passa por plano, implementação com testes, revisão independente e correções antes de ser dada como concluída.

  1. Esqueleto do projeto React + Vite, servidor Express, testes, lint e build.
  2. Regras de negócio Dinheiro em centavos, preço médio, variação, datas e códigos da B3.
  3. Banco de dados e API local SQLite com compras, ações escolhidas e uso das APIs.
  4. Catálogo, logos e alertas (4a) · Cotações do Yahoo (4b) Fontes gratuitas, reserva automática e monitoramento das APIs.
  5. Grade na tela e rodapé Quadrados, atualização a cada 5 min, fonte em uso e avisos.
  6. Destaque dos vizinhos Mouse, toque e teclado.
  7. Menu e escolha das ações Lista com caixas de seleção e limite de 50.
  8. Tela de compras Cadastrar, editar e excluir.
  9. Setas de ganho e perda Preço atual comparado ao preço médio.
  10. Iniciar com dois cliques iniciar.bat, guia de uso e teste ponta a ponta.
ℹ

O servidor, a lógica, a grade de cotações com o rodapé, o destaque dos vizinhos e o menu de escolha das ações já estão prontos e testados; a tela de compras e as setas chegam nas próximas etapas. Os capítulos marcam o que já existe com pronto e o que vem depois com próximas etapas.

Instalar e rodar

Tudo roda no próprio Windows, sem hospedagem e sem banco para instalar.

O que você precisa

  • Node.js 24 ou mais novo (o banco embutido do Node exige essa versão).
  • Nada mais: o SQLite já vem dentro do Node, e nenhuma API pede chave.

Passo a passo

  1. Instale as dependências na pasta do projeto: 
    npm install
  2. (Opcional) Copie .env.example para .env para mudar a porta ou o arquivo do banco. Sem isso, valem os padrões.
  3. Gere a versão final e inicie o servidor: 
    npm run build
npm start
  4. Abra http://localhost:3000 no navegador.

Comandos

Comando O que faz
npm run dev Modo de desenvolvimento: tela (Vite) e servidor recarregam sozinhos ao salvar.
npm test Roda todos os testes automáticos.
npm run lint Confere estilo e erros comuns (ESLint + Prettier).
npm run build Confere os tipos e gera a versão final em dist/.
npm start Serve a versão final em http://localhost:3000.

Configuração (.env)

Variável Padrão Para quê
PORT 3000 Porta do servidor local.
DB_ARQUIVO dados.db Arquivo do banco (caminho absoluto ou relativo à pasta do projeto).
⛔

Não existe variável de chave de API — de propósito. O app só usa fontes gratuitas e sem cadastro. Veja o capítulo Custo zero e segurança.

⚠

Porta ocupada? Se aparecer “A porta 3000 já está em uso. O dashboard já está aberto?”, o app provavelmente já está rodando em outra janela.

Capítulo 04 · Funcionalidades

A tela do dashboard grade, rodapé, destaque e menu prontos

Grade, atualização automática, rodapé, destaque e escolha das ações já funcionam; a tela de compras e as setas chegam nas próximas etapas.

Os quadrados

Cada ação escolhida vira um quadrado do mesmo tamanho, com logo, código e preço atual (as setas chegam na etapa 9; logo que falha vira as iniciais; preço antigo ganha o selo “desatualizado”):

BBBBAS3R$ 17,38 ▲ +4,21%
PBPETR4R$ 52,79 ▼ −2,10%
B3B3SA3R$ 15,40 sem compras
  • Seta verde com % de ganho quando o preço atual está acima do seu preço médio.
  • Seta vermelha com % de perda quando está abaixo.
  • Exatamente igual: mostra 0,00% sem seta.
  • Sem compras registradas: só o preço.

Telas menores

A grade usa CSS Grid com auto-fill: em telas menores cabem menos colunas e as demais ações ficam acessíveis rolando a página. Os quadrados continuam quadrados.

Destaque dos vizinhos pronto

O quadrado ativo ganha destaque forte (fundo e anel na cor de destaque) e os 4 vizinhos (acima, abaixo, esquerda e direita) um tom suave. O fim de uma linha não é vizinho do começo da próxima. O número de colunas é lido do layout real e relido ao redimensionar a janela; o cálculo dos vizinhos é uma função pura testada. No alto contraste do Windows, o ativo ganha contorno sólido e os vizinhos, tracejado.

Dispositivo Como ativa
Mouse Passar por cima destaca; sair da grade apaga. Só em aparelhos com hover.
Toque Um toque liga; de novo no mesmo quadrado desliga; em outro, muda. Tocar fora da grade ou no vão entre os quadrados apaga. Rolar a página não liga.
Teclado Tab entra na grade (um só ponto de parada); setas, Home e End movem; Esc apaga. Atalhos com Alt, Ctrl ou Shift continuam com o navegador.

Atualização automática pronto

Quando O que a tela faz
Ao abrir Busca as cotações de todas as ações escolhidas.
A cada 5 minutos Busca de novo. O servidor decide se precisa chamar o Yahoo ou a brapi.
Ação ainda sem preço Pergunta de novo em 10 s, no máximo 3 vezes por ação.
Servidor fora do ar Mantém os últimos preços, avisa e tenta de novo em 1 minuto.
Aba escondida Não busca; ao voltar, busca na hora se a vez dela já passou.

Cabeçalho e rodapé pronto

  • Cabeçalho: “Mercado aberto”, “Mercado fechado · último fechamento” ou “Pregão de hoje ainda não confirmado”, e “Atualizado em dd/mm/aaaa hh:mm” (horário de Brasília).
  • Rodapé: qual API está em uso (“Cotações: Yahoo Finance”, ou “brapi (reserva)”) e um aviso para cada API indisponível, que passou a exigir pagamento ou que mudou de formato — com o horário da próxima verificação.
  • Ações que o Yahoo não conhece aparecem em “Sem cotação no Yahoo”.
  • Uma resposta estranha do servidor nunca deixa a página em branco: um item inválido é ignorado sozinho, e qualquer erro inesperado vira uma mensagem.

Menu e escolha das ações pronto

O botão ☰ Menu, no canto superior direito, tem duas opções: Escolher ações e Registrar compras (desabilitada até a etapa 8). Sem nenhuma ação escolhida, a tela mostra “Nenhuma ação selecionada” e indica o menu.

  1. Abra Menu → Escolher ações. Um painel abre à direita (a tela toda no celular) com o campo de busca já em foco.
  2. Busque por código ou nome, sem se preocupar com acentos: “itau” encontra Itaú Unibanco.
  3. Marque e desmarque as caixas. O contador mostra “N de 50 selecionadas”; ao chegar a 50, as caixas desmarcadas ficam desabilitadas até você desmarcar alguma.
  4. Clique em Salvar. As cotações são buscadas na hora e as novas ações entram no fim da grade, na ordem em que foram marcadas.
Situação O que o painel faz
Marcações antes de salvar São um rascunho: Cancelar ou Esc descartam. Assim cada clique não gasta uma chamada ao Yahoo.
Ordem da grade As ações já salvas ficam no topo da lista e mantêm o lugar na grade; desmarcar e marcar de novo não muda a ordem.
Ação salva que saiu da lista da B3 Continua na lista, marcada, com “fora da lista atual da B3”, para desmarcar.
Lista de ações não carrega Mostra as já escolhidas (com “nome indisponível”), avisa e oferece Tentar de novo. Vale também quando a brapi ainda não foi baixada nenhuma vez. A lista é pedida à brapi no máximo a cada 15 minutos, então novas tentativas nesse intervalo repetem o aviso.
Servidor demora Depois de 20 s, carregar ou salvar desiste e oferece tentar de novo. Se foi o salvamento, avisa que ele pode ter sido gravado e a grade confere na hora.
Salvar falha Mostra o motivo e mantém as marcações para tentar de novo.
Salvando Caixas, busca, Cancelar e Esc ficam travados até terminar.

Teclado: Tab circula só dentro do painel (o foco nunca escapa para a grade, nem depois de clicar em Salvar); Esc com texto na busca limpa a busca, e com a busca vazia fecha o painel. A lista mostra código e nome, sem logo: o catálogo tem centenas de ações, e rolar pediria centenas de logos à brapi.

Compras e preço médio pronto no servidor

Cada compra fica registrada no banco local e pode ser editada ou excluída.

O que é guardado

Campo Regra
Código (ticker) Formato da B3, como BBAS3, TAEE11 ou B3SA3.
Data Data válida, nunca no futuro (pelo horário de Brasília).
Quantidade Inteiro de 1 a 1.000.000.000.
Preço unitário Maior que zero, até R$ 1.000.000,00.
Taxas Zero ou mais, até R$ 1.000.000,00.
Plataforma Texto de 1 a 40 caracteres (ex.: Itaú Íon, BTG), sem caracteres invisíveis ou de controle.

O valor total de uma compra (quantidade × preço + taxas) não pode passar de R$ 100 bilhões.

Como o preço médio é calculado

preço médio = (soma de quantidade × preço unitário + soma das taxas) ÷ quantidade total

Exemplo: duas compras de BBAS3.

Compra Quantidade Preço Taxas Valor pago
1ª 100 R$ 16,00 R$ 4,90 R$ 1.604,90
2ª 50 R$ 18,00 R$ 4,90 R$ 904,90
Total 150 R$ 2.509,80

Preço médio = R$ 2.509,80 ÷ 150 = R$ 16,73. Com a ação a R$ 17,38, a variação é (17,38 × 150 − 2.509,80) ÷ 2.509,80 = ▲ +3,87%.

ℹ

A variação é calculada sobre o custo total exato, não sobre o preço médio arredondado. Assim, centavos de arredondamento nunca mudam a cor da seta.

⚠

Vendas estão fora do escopo: o app registra apenas compras. Se uma ação tiver dados problemáticos, só ela fica sem posição — as demais continuam funcionando.

Capítulo 06 · Funcionalidades

Cotações pronto no servidor

De onde vêm os preços, com que frequência são atualizados e o que acontece quando algo falha.

As fontes

Fonte Papel Detalhes
Yahoo Finance
v7/finance/spark		 Principal Sem chave, conta, cookie ou “crumb”. Até 20 ações por chamada (limite do Yahoo): 50 ações = 3 chamadas. Envia só User-Agent: Mozilla/5.0, que o Yahoo exige.
brapi
/api/quote/list		 Reserva Listagem pública sem chave: uma chamada traz todas as ações com nome, logo e último preço. No máximo a cada 15 minutos.
Banco local Último recurso O último preço conhecido de cada ação fica salvo e aparece marcado como desatualizado.

Ritmo de atualização

O horário do pregão vem do próprio Yahoo, então feriados não precisam de calendário. O ritmo de cada ação depende da situação do pregão:

Situação Quando Atualiza a cada
Aberto Pregão regular (hoje, 10h às 17h) 5 minutos
Leilão Até 30 min após o fim — quando sai o preço de fechamento (~17h10) 5 minutos
Desconhecido Dia útil no horário de pregão (a partir de 1 h antes), mas o Yahoo ainda não confirmou o pregão do dia — início da manhã ou feriado 15 minutos (5 nos primeiros 30 min após a abertura prevista)
Fechado Noite e fim de semana 1 hora

Além disso, há duas buscas obrigatórias por dia:

  • Fim do leilão (30 min após o fechamento): garante o preço de fechamento definitivo.
  • Abertura prevista: descobre logo o pregão do dia.
ℹ

As buscas só acontecem quando a tela pede cotações. Com o app fechado, nenhuma chamada sai do seu computador.

Ações recém-marcadas e pedidos simultâneos

  • Uma ação nova é buscada na hora, sem repetir as que já estão em dia.
  • As rodadas de chamadas ao Yahoo acontecem uma de cada vez; pedidos que chegam durante uma rodada entram juntos na próxima.
  • Há pelo menos 5 segundos entre rodadas que chamaram o Yahoo.
  • A rota de cotações espera no máximo 8 segundos e então responde com os dados salvos; a busca termina sozinha e vale para o próximo pedido.

Quando o Yahoo não responde

  1. O app continua mostrando o último preço do Yahoo, marcado como desatualizado depois de perder duas atualizações.
  2. Depois de 30 minutos sem atualizar, entra o preço da brapi — nunca um preço da brapi mais antigo que o do Yahoo. Isso evita que a fonte fique alternando a cada falha curta.
  3. Ações que o Yahoo não conhece (ex.: ELET3, que virou AXIA3) usam a brapi direto e aparecem em “sem cotação no Yahoo”.
  4. Sem nenhuma fonte, fica o último preço salvo. Se nunca houve preço, a ação aparece sem preço.

Capítulo 07 · Funcionalidades

Catálogo e logos pronto no servidor

A lista de ações disponíveis para escolher e as imagens dos logos.

Catálogo

  • Vem da listagem pública da brapi: cerca de 380 ações (sem o mercado fracionário, como BBAS3F).
  • Atualizado no máximo a cada 15 minutos, só quando alguém consulta.
  • Busca sem acentos e sem diferenciar maiúsculas: “itau” encontra “ITAÚ UNIBANCO”.
  • Ações que saem da listagem continuam no catálogo com o último preço conhecido.

Logos: baixados uma vez, conferidos uma vez por dia

  1. No primeiro pedido, o logo é baixado e salvo no banco.
  2. Nos pedidos seguintes, sai direto do banco — nenhuma chamada externa.
  3. Uma vez por dia, o app confere se o logo mudou (ETag). Se não mudou, nada é baixado.
  4. O navegador também guarda o logo por um dia.
  • No máximo 4 downloads de logo ao mesmo tempo.
  • Falha temporária no primeiro download: nova tentativa em 15 minutos, não no dia seguinte.
  • Logo com problema próprio (grande demais, formato estranho) afeta só aquela ação; 5 seguidos com problema indicam mudança no servidor de logos e geram alerta.
  • Só são aceitos SVG e PNG de até 200 KB.

Alertas das APIs pronto no servidor

Se uma API mudar as regras — passar a cobrar, exigir cadastro ou mudar o formato —, o app percebe, avisa e continua funcionando com os dados salvos.

As quatro situações

Situação Quando O que o app faz
ok Respondeu normalmente. Usa os dados. Pode mostrar um aviso (ex.: aviso de cobrança junto com dados válidos).
instável Sem internet, demora (10 s), erro 5xx, limite de requisições (429) ou acesso recusado sem sinal de cobrança. Tenta de novo no próximo ciclo, respeitando o tempo pedido pela API (até 24 h).
bloqueada Pagamento exigido (402), cabeçalhos de cobrança ou mensagem pedindo chave, plano ou assinatura. Não chama mais por 24 horas; usa a reserva ou os dados salvos.
formato alterado A resposta não tem mais o formato esperado. Não chama mais por 24 horas; usa a reserva ou os dados salvos.
✓

Cuidados para não dar alarme falso Uma ação suspensa ou desconhecida não pausa o Yahoo — nem um lote só com ações que ele não conhece, que o Yahoo responde com 404; um erro 401/403 comum (ex.: proteção anti-robô) não é tratado como “exige pagamento”; e nomes de empresas como “Plano & Plano” não disparam o alerta de cobrança.

Monitoradas separadamente

  • yahoo — cotações.
  • brapi — listagem (catálogo e preços de reserva).
  • brapi_icones — imagens dos logos.

Cada chamada externa é contada por mês na tabela uso_api. Pequenos acertos do relógio do Windows não liberam um bloqueio antes da hora.

Regras de negócio

As regras ficam em src/shared e valem igual na tela e no servidor.

Dinheiro

  • Sempre guardado em centavos inteiros, nunca em número quebrado: R$ 17,38 vira 1738.
  • Divisões exatas com inteiros grandes (BigInt) e arredondamento “meio para longe do zero”.
  • Exibição no padrão brasileiro: R$ 1.234,56.
  • Valores digitados aceitam 1.234,56, 1234,5 ou 1234.

Percentual

Guardado em centésimos de ponto: 1234 = 12,34%. Exibição: +12,34%, -5,67% ou 0,00%.

Datas e horários

  • Datas exibidas como dd/mm/aaaa e guardadas como aaaa-mm-dd.
  • “Hoje” sempre no horário de Brasília, independentemente do relógio do sistema.

Códigos de ação

Quatro caracteres (letra seguida de letras ou números) e 1 ou 2 dígitos finais: BBAS3, TAEE11, B3SA3. Minúsculas são convertidas; códigos como IBOV ou BBAS3F são recusados.

Banco de dados

Um arquivo SQLite (dados.db) que sobrevive ao fechar o navegador e o app.

Tabela Guarda
transacoes Compras: ticker, data, quantidade, preço e taxas em centavos, plataforma.
acoes_selecionadas Ações exibidas, na ordem escolhida (o banco recusa mais de 50).
catalogo Ações da brapi com nome, endereço do logo e último preço.
logos Imagem do logo, tipo, ETag e quando foi conferido.
cotacoes Último preço de cada ação, fonte, horário da negociação e da atualização.
pregao Horário do pregão mais recente informado pelo Yahoo.
estado_api Situação de cada API, desde quando e quando tentar de novo.
uso_api Quantas chamadas cada API recebeu por mês.

Proteções

  • Regras no próprio banco (tipos estritos e verificações): preço zero, ticker inválido ou data impossível são recusados mesmo que algo escape da validação.
  • Antes de atualizar a estrutura de um banco existente, uma cópia de segurança é criada (dados.db.bak-v…).
  • Atualizações de estrutura acontecem numa única transação: ou tudo, ou nada.
  • Ao fechar o app, o banco é gravado por completo antes de encerrar.
⚠

O banco, as cópias de segurança e o .env nunca vão para o git.

Custo zero e segurança

A garantia de nunca pagar por uma API está no código, não só na intenção.

⛔

Regra absoluta Nunca usar API que exija chave, conta, plano ou pagamento. Nenhuma chave no código, no .env ou nas requisições.

Como o código garante isso

Toda chamada à internet passa por uma única função, requisitarExterno, que:

  • só aceita HTTPS e uma lista fechada de endereços: brapi.dev, icons.brapi.dev e query1.finance.yahoo.com;
  • só aceita os parâmetros previstos para cada endereço — um parâmetro de chave não consegue nem ser montado;
  • recusa cabeçalhos de autenticação e cookies;
  • não segue redirecionamentos, limita o tamanho da resposta e desiste após 10 segundos.

Proteção do servidor local

  • O servidor escuta só em 127.0.0.1 e recusa pedidos com outro endereço no cabeçalho Host (proteção contra “DNS rebinding”).
  • Logos são servidos com política de conteúdo restrita: um SVG não consegue executar código.
  • Erros internos nunca expõem detalhes; a resposta é só “Erro interno do servidor”.

Testes e qualidade

Cada etapa só termina quando testes, lint e build passam e a revisão é atendida.

O ciclo de cada etapa

  1. Plano apresentado e aprovado antes de qualquer código.
  2. Implementação com testes automáticos.
  3. Verificação: testes, lint, build e revisão por um agente revisor independente.
  4. Correções de tudo o que a revisão apontar, em até 3 rodadas.
  5. Commit com mensagem em português.

Glossário

Ticker Código da ação na B3, como BBAS3.
Pregão Período de negociação da bolsa (hoje, 10h às 17h em Brasília).
Leilão de fechamento Minutos após o pregão em que se define o preço de fechamento.
Preço médio Tudo o que foi pago (com taxas) dividido pela quantidade comprada.
Fonte principal / reserva Yahoo Finance / listagem da brapi.
Lote Grupo de até 20 ações pedidas ao Yahoo numa só chamada.
Rodada Conjunto de lotes buscados de uma vez; só uma por vez, com pausa entre elas.
ETag “Impressão digital” de um arquivo, usada para saber se o logo mudou sem baixá-lo.
Migração Atualização da estrutura do banco, aplicada automaticamente ao abrir o app.
Crumb Senha temporária que alguns endpoints do Yahoo exigem — o app usa um que não exige.
